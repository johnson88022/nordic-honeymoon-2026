# 北歐蜜月｜交通與行前手冊 2026

這是可直接部署到 GitHub Pages 的靜態網站，沒有建置步驟。網站包含 2026/11/23–12/08 的 16 天行程、交通路線示意圖、天氣查核入口、行前安全資訊、交通 App 與原始費用紀錄。

## 上傳到 GitHub Pages

建議新 repository 名稱：`nordic-honeymoon-2026`。把本資料夾內的 `index.html`、`route-map.svg`、`README.md` 放在新 repository 的根目錄，然後在 GitHub 的 **Settings → Pages** 選擇 **Deploy from a branch → main → /(root)**。網站網址會是：

`https://johnson88022.github.io/nordic-honeymoon-2026/`

## 重要使用說明

- 星期標籤已核對；所有出發時間、航班、渡輪、夜車、公車、活動與住宿安排，除非旅客的正式訂單已核對，均應視為待確認。
- 天氣查核基準日為 **2026/11/11**。當時 Yr 的 Oslo 10 日預報只到 11/20，尚未涵蓋 11/23–12/08；網站提供各城市的即時官方查詢入口，不填虛構逐日溫度或降水。
- `route-map.svg` 是不按比例的路線順序示意圖，不可作現場導航。營運商票券上的碼頭、站名、班號與登船截止時間優先。
- Lofoten 冬季路況及班次以 Reis、Statens vegvesen 和當地天氣為準；路況不穩時優先取消額外戶外活動。
- 網站的入境與 ETIAS 資訊以官方頁面 **2026/11/11** 查核結果為準，出發前仍須再次確認政策是否更新。

## 檔案

- `index.html`：互動式每日行程、路線總覽、天氣／安全頁與費用表。
- `route-map.svg`：全程交通順序圖；可單獨分享或縮放查看。
- `README.md`：部署步驟與使用限制。
